    Reading the piles

    Write each pile as a sum of blocks of 8, 4, 2 and 1 stones. Call the position balanced when every block size appears an even number of times. The position 1, 4, 5 is balanced: 5 is 4 + 1, so there are two 4s and two 1s.

    Balance is the whole game. A move changes one pile only, so it always breaks a balanced position: the blocks of that pile change, and nothing else moves to make up for it. An unbalanced position can always be repaired. Find the largest block size held an odd number of times, pick a pile holding it, and rebuild that pile so every odd size flips. Removing that large block frees enough room for the smaller ones.

    The empty board is balanced. So whoever hands over a balanced position every turn takes the last stone. C. L. Bouton published this complete solution in 1901. Adding piles without carrying, which is what the table does, is now called the nim-sum.

    The misère game, where the last stone loses, needs one change. Play the same way until your move would leave only single stones, then leave an odd number of them. While any pile holds two or more stones, the two games agree on who is winning.

      Why a row is a pile in disguise

      A run of pins can be swapped for one Nim pile without changing who wins any game it is part of. Roland Sprague and Patrick Grundy proved this independently in the 1930s, for every game of this kind. The size of that pile is the run's nimber.

      To find it, list the values a move can reach and take the smallest one missing. In Kayles, a run of 4 can become 3 pins (worth 3), 1 and 2 (worth 1 and 2, nim-sum 3), 2 pins (worth 2), or 1 and 1 (nim-sum 0). The values 0, 2 and 3 are reachable and 1 is missing, so the run of 4 is worth 1.

      A move splits one run into two, so a row is a sum of separate games. Its value is the nim-sum of its runs, and a move wins exactly when it brings that sum to zero, the same rule as in Piles.

      Kayles is Henry Dudeney's puzzle of 1908, and Richard Guy and Cedric Smith worked out its values in 1956. Its opening player always has a win: fell the middle pin or the middle two, then mirror every reply. Their periodicity test shows why a finite table can settle the game for all lengths: once the values repeat for long enough, each new value only depends on values that already repeat.

      Officers gets no such certificate here. Set the wall to any width you like: Achim Flammenkamp's tables of octal games, computed far past this page, list no period for it, and whether every game of this family eventually repeats is an open question.

        The golden ratio in a game of stones

        The queen's two coordinates are two piles of stones. Moving left or down takes from one pile, and moving diagonally takes the same number from both. W. A. Wythoff published the solution in 1907.

        Call a square cold if whoever must move from it loses. The corner is cold. Every square that can reach a cold square in one move is hot. The first square left over is cold again, and it rules out its own row, column and diagonal. So each column, row and diagonal holds exactly one cold square.

        The rule is simple, and its result is exact: the k-th cold square has a smaller coordinate of ⌊kφ⌋ and a larger one of ⌊kφ²⌋, which is the smaller plus k, where φ is the golden ratio. Since 1/φ + 1/φ² = 1, these two sequences together use every positive whole number exactly once, which is what the columns and rows above needed.

        Cold squares are the squares worth 0. Every other value comes from the same smallest-missing rule as in Rows, and the map above shows how much that one extra diagonal move disturbs Nim's tidy squares.
