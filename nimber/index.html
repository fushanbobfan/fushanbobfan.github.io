Two players take turns removing stones from one pile at a time. It looks like a game of nerve. Every position has already been decided, and you can learn to read the verdict.

    Reading the piles

    Write each pile as a sum of blocks of 8, 4, 2 and 1 stones. Call the position balanced when every block size appears an even number of times. The position 1, 4, 5 is balanced: 5 is 4 + 1, so there are two 4s and two 1s.

    Balance is the whole game. A move changes one pile only, so it always breaks a balanced position: the blocks of that pile change, and nothing else moves to make up for it. An unbalanced position can always be repaired. Find the largest block size held an odd number of times, pick a pile holding it, and rebuild that pile so every odd size flips. Removing that large block frees enough room for the smaller ones.

    The empty board is balanced. So whoever hands over a balanced position every turn takes the last stone. C. L. Bouton published this complete solution in 1901. Adding piles without carrying, which is what the table does, is now called the nim-sum.

    The misère game, where the last stone loses, needs one change. Play the same way until your move would leave only single stones, then leave an odd number of them. While any pile holds two or more stones, the two games agree on who is winning.
