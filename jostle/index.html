jostle

Start every disk at the same speed and let them collide. Nothing in the rules prefers any speed, yet within a few hundred collisions the histogram takes the shape Maxwell wrote down in 1860, and Boltzmann's H falls to its floor and stays there. Each collision is exactly elastic, so the total energy never changes; only the way it is shared out does.

Space pauses, S steps, R restarts with the same seed, N draws a new one.
